## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

- Preserve local-first desktop scope: no new backend, hosted service, or
  credential requirement for core behavior unless the feature spec explicitly
  approves it.
- Preserve minimal-footprint UI: default expanded and collapsed states must
  remain readable in a small floating window; extra controls or text must be
  transient, opt-in, or justified.
- Protect feed integrity: stale, missing, reconnecting, or placeholder market
  data must not be treated as fresh, and derived behaviors must define safe
  degraded handling.
- Prefer additive evolution inside `terminal_ticker/` and `tests/`; broad
  refactors, runtime swaps, or new frameworks require explicit justification in
  Complexity Tracking.
- Define automated verification for every user-visible behavior, config rule,
  parser path, or state transition touched by the feature.
